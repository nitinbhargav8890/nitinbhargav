# Login Page – HTML & CSS Task

A simple, responsive-style login page built using only **HTML** and **CSS** (no Bootstrap), as part of the TuteDude assignment to learn basic CSS properties.

## Project Structure

```
YourName_Task(number)/
├── index.html
├── index.css
└── Readme.md
```

## Features

- **Container Setup:** A centred container with a height of `100vh`, aligned using Flexbox.
- **Left Section:** An image displayed on the left side of the container.
- **Form Section:** A login form section on the right with proper padding, laid out using Flexbox.
- **Heading & Description:** A friendly greeting heading with a short description.
- **Email & Password Inputs:** Input fields with appropriate `type` attributes and `placeholder` text, styled to look clean and organised.
- **Login Button:** A button labelled "Login", styled to stand out and look appealing.

## Technologies Used

- HTML5
- CSS3 (Flexbox, padding, margin)

## How to Run

1. Download or clone the project folder.
2. Make sure `index.html` and `index.css` are in the same folder.
3. Open `index.html` in any web browser.

## Concepts Practised

- Flexbox for layout and centring
- Margin and padding
- Styling form inputs and buttons
- Linking an external CSS file to HTML
